# AI Career Intelligence Platform

This repository contains the initial scaffold for a monorepo-based AI career intelligence platform.

## Structure

- backend/: FastAPI application and services
- frontend/: React + Vite frontend
- prompts/: reusable LLM prompt templates
- docs/: architecture notes and task tracking

## Quick start

1. Copy .env.example to .env and adjust credentials.
2. Run docker compose up --build.
3. Open http://localhost:5173 for the frontend and http://localhost:8000/docs for the API.
